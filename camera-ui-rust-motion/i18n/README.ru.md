# Rust Motion

Обнаруживает движение на изображении с камеры при низкой нагрузке на процессор. Замечает в том числе мелкое и медленное движение.

## Возможности

- Обнаруживает движение на изображении с камеры и отмечает области, где что-то движется
- Мало нагружает процессор и не требует видеокарты
- Надёжно обнаруживает мелкое и медленное движение, днём и ночью
- Считает близко расположенные изменившиеся области одним движением: животное вдалеке — это одно обнаружение, а не несколько точек
- После смещения камеры или резкой смены экспозиции начинает заново, а не отмечает всё изображение
- Отдельные настройки для каждой камеры и кнопка, которая возвращает значения по умолчанию

## Что потребуется

- Детектор доступен не для каждой серверной системы. Если для вашей его нет, плагин не добавит камерам датчик движения

## Настройки

- «Площадь»: минимальный суммарный размер соседних изменившихся областей, который считается движением
- «Порог»: изменение яркости, при котором пиксель считается изменившимся
- «Радиус размытия»: сглаживает изображение перед обнаружением, чтобы снизить шум
- «Размер расширения»: объединяет соседние изменившиеся пиксели в одну область
- «Удержание эталона»: сколько секунд хранится кадр для сравнения. Большие значения улавливают очень медленное движение, меньшие держат рамки движения ближе к текущему положению
