# ONNX Legacy

Обнаружение объектов, лиц и номерных знаков для старых видеокарт NVIDIA и для систем, остающихся на CUDA 12. С обычным плагином ONNX обнаружение на таких картах молча переходит на процессор.

## Возможности

- Обнаружение объектов: люди, транспорт и животные
- Обнаружение лиц и распознавание лиц
- Находит номерные знаки и читает их текст
- ИИ-поиск по описанию
- Находит похожих людей на разных камерах (идентификация людей, включается для каждой камеры) и обводит людей, транспорт и животных (сегментация)

## Что потребуется

- Используйте его вместо обычного плагина ONNX, если ваша видеокарта NVIDIA старше GTX 1650: Maxwell (серии GTX 700/900), Pascal (серия GTX 10, Quadro от P400 до P4000, Tesla P4/P40/P100) или Volta (Titan V, Tesla V100)
- Или если вы хотите оставить установленную CUDA 12
- CUDA 12.x, cuDNN 9.x для CUDA 12 и драйвер NVIDIA 525 или новее
- Linux или Windows
- На GTX 1650 и новее используйте обычный плагин ONNX: он работает с CUDA 13, напрямую поддерживает серию RTX 50 и продолжает получать исправления

## Настройки

- «Провайдер выполнения»: 'auto' использует CUDA в Linux и Windows (x86_64), в остальных случаях — процессор; с 'tensorrt' (NVIDIA TensorRT) первый запуск дольше. При сбое работает процессор.
- «ID устройств CUDA»: какие видеокарты использовать, например "0,1"
- «Модель CLIP (изображения)»: модель ИИ-поиска для всех камер. После её смены переиндексируйте записи.
- «Модель распознавания лиц»: одна модель для всех камер. После смены сохранённые лица обрабатываются заново.
- Для каждой камеры: модели обнаружения объектов, обнаружения лиц и номерных знаков. «По умолчанию» следует рекомендуемой модели.
