# Apple LLM

Предлагает ассистенту ViON языковую модель, встроенную в ваш Mac. Модель отвечает на том Mac, где работает плагин: ключ не нужен, и в облако ничего не отправляется.

## Возможности

- Добавляет встроенную модель Apple в список моделей, которые можно выбрать в настройках ассистента.
- Через эту модель ассистент может обращаться к событиям, камерам и датчикам.
- Ответ появляется слово за словом, а отменённый вопрос сразу останавливает модель.
- На macOS 27 модель также смотрит на кадры событий.
- Всё остаётся на Mac: без учётной записи, без ключа, без облака.

## Что потребуется

- Mac с Apple Silicon и macOS 26 или новее, на котором работает ViON.
- Включённый Apple Intelligence в системных настройках Mac. Пока macOS загружает модель, ViON её ещё не предлагает.
- macOS 27, если модель должна видеть изображения.

## Настройки

- «Запрашивать структурированные ответы»: Apple отказывается отвечать обычным текстом о людях у дверей, ворот и окон. С этой настройкой модель отвечает на такие вопросы.
- «Смягчённый фильтр безопасности»: модель реже отказывается описывать обычные сцены с камер.
- «Окно контекста (токены)»: увеличьте после обновления системы, которое расширяет окно.
- «Разрешить модели использовать инструменты»: если выключить, модель только ведёт разговор и не может обращаться к событиям, камерам и датчикам.
- «Отправлять изображения модели»: работает только на macOS 27.
