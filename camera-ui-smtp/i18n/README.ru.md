# SMTP

Превращает письмо, которое камера отправляет при движении, в событие движения в ViON. Плагин запускает небольшой почтовый сервер, на который камера отправляет свои оповещения.

## Возможности

- Принимает письма-оповещения камер прямо на сервере ViON, без стороннего почтового сервиса
- Добавляет каждой камере датчик движения со своим адресом электронной почты: письмо на этот адрес сообщает о движении
- Может считать движением только письма с определённым текстом
- Может завершать движение, когда приходит письмо с другим текстом
- Принимает от камеры любые имя пользователя и пароль, поэтому заводить почтовый ящик не нужно

## Что потребуется

- Камера, которая умеет отправлять письмо при обнаружении движения
- В настройках почты камеры: адрес сервера ViON в качестве почтового сервера (SMTP), порт из настроек плагина и в качестве получателя — адрес, который вы указали для этой камеры в ViON

## Настройки

Плагин:

- **Порт** — порт, на котором почтовый сервер принимает письма, по умолчанию 25
- **Отключить TLS** — включите для камер, которые не поддерживают шифрованное соединение (STARTTLS)

Датчик движения каждой камеры:

- **Адрес электронной почты** — адрес получателя, который обозначает эту камеру; имя и домен могут быть любыми
- **Текст начала движения** — текст, который должен быть в теле письма, чтобы сообщить о движении. Оставьте пустым, чтобы срабатывать на любое письмо
- **Текст окончания движения** — текст в теле письма, который завершает движение
