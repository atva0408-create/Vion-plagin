# CoreML

Обнаруживает объекты, лица и номерные знаки на видео с ваших камер на компьютере Mac с помощью Apple CoreML и обеспечивает семантический поиск (CLIP).

## Возможности

- Обнаруживает людей, транспорт и животных
- Обнаруживает лица и узнаёт знакомых людей
- Обнаруживает номерные знаки и читает их текст
- Обеспечивает семантический поиск CLIP по событиям
- Учитывает значения уверенности из настроек обнаружения камеры
- Позволяет выбрать, какие части оборудования Apple выполняют работу: CPU, GPU и Neural Engine
- Сам скачивает модели

## Что потребуется

- Сервер ViON, работающий на компьютере Mac (macOS)
- Чтобы лица получали имена, этот плагин нужно выбрать в пункте «Распознавание лиц» для каждой камеры: настройки камеры, «Плагины», «Обнаружения»

## Настройки

- **Модель CLIP (изображения)**: модель для семантического поиска, общая для всех камер. После её смены записи нужно переиндексировать
- **Модель распознавания лиц**: общая для всех камер. После её смены сохранённые лица будут пересчитаны
- **Вычислительные блоки**: где CoreML выполняет модели. ALL использует CPU, GPU и Neural Engine; остальные варианты используют только часть из них
- **Активное оборудование**: показывает, где работают модели
- **Скачать модели заново**: удаляет скачанные модели и скачивает актуальные
- **Сбросить настройки**: возвращает все настройки плагина к значениям по умолчанию
- Для каждой камеры, в группах «Обнаружение объектов», «Обнаружение лиц» и «Номерные знаки»: **Модель**, **Модель детектора** и **Модель OCR**. Вариант «По умолчанию» следует рекомендуемой модели
