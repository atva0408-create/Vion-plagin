# Coral

Обнаруживает людей, транспорт и животных на изображении с камер и использует для обнаружения ускоритель Coral Edge TPU.

## Возможности

- Обнаруживает людей, транспорт и животных на видео с ваших камер
- Выполняет обнаружение на Coral Edge TPU и переходит на процессор, если Edge TPU недоступен
- Позволяет выбрать, какой Edge TPU использовать, если подключено несколько
- Учитывает значения уверенности, заданные для каждого типа объектов (человек, транспорт, животное) в настройках обнаружения камеры
- Сам скачивает модель

## Что потребуется

- Сервер ViON под управлением Linux (x64 или ARM64)
- Coral Edge TPU, подключённый по USB или PCIe, и установленное на сервере системное программное обеспечение Edge TPU (libedgetpu). Без них плагин тоже работает, но на процессоре

## Настройки

- **Использовать Edge TPU (Coral)**: если включено, обнаружение выполняется на Coral Edge TPU, когда он доступен; иначе используется процессор
- **Устройство Edge TPU**: какой Edge TPU использовать, если подключено несколько: "usb", "pci", ":0", ":1" или "usb:0". Оставьте поле пустым, чтобы использовать первый доступный
- **Активное оборудование**: показывает, где работают модели
- **Скачать модели заново**: удаляет скачанные модели и скачивает актуальные
- **Сбросить настройки**: возвращает все настройки плагина к значениям по умолчанию
- **Модель**: задаётся для каждой камеры в группе «Обнаружение объектов». Вариант «По умолчанию» следует рекомендуемой модели
