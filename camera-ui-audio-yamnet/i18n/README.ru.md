# YAMNet Audio Detection

Анализирует звук с ваших камер, распознаёт характерные звуки, например разбитие стекла, сирену или лай собаки, и сообщает о них ViON.

## Возможности

- Распознаёт двенадцать видов звуков: дверной звонок, разбитие стекла, сирена, речь, выстрел, лай собаки, плач ребёнка, сигнализация, крик, кошка, автосигнализация и дымовая сигнализация
- Сообщает о каждом звуке один раз и под теми названиями, которые ViON использует для звуков
- Использует значение уверенности из настроек камеры, поэтому чувствительность задаётся для каждой камеры в одном месте
- Не требует собственной настройки: плагин всегда отслеживает все эти звуки
- Сам скачивает модель при первом запуске
- Работает на процессоре сервера

## Что потребуется

- Камера, передающая звук

## Настройки

- У плагина нет собственных настроек. Насколько уверенным он должен быть, чтобы сообщить о звуке, задаётся для каждой камеры параметром «Уверенность для звука» в настройках камеры; если он не задан, действует значение 0.7
- **Отслеживаемые звуки** и **Порог уверенности** используются только при тестировании обнаружения
