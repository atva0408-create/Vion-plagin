# Home Assistant

Переносит устройства вашего Home Assistant в ViON и доставляет уведомления ViON через Home Assistant.

## Возможности

- Показывает подходящие сущности Home Assistant в разделе «Обнаруженные» на странице «Датчики» — с названием, типом и комнатой; вы добавляете нужные
- Превращает сущности движения, присутствия, контакта, дверного звонка, дыма, протечки, газа, угарного газа и другие поддерживаемые в датчики ViON, которые можно назначить камерам для запуска обнаружения
- Добавляет замки, гаражные ворота, охранные панели, выключатели, свет и сирены как элементы управления: переключение в ViON переключает их в Home Assistant
- Предлагает службы уведомлений Home Assistant (мобильное приложение, Telegram и другие) как получателей уведомлений в разделе «Настройки» > «Уведомления»
- Сохраняет датчик и его назначения камерам, когда сущность переименована в Home Assistant, и отмечает его как удалённый, когда сущность там удалена
- Никогда не предлагает сущности, которые ViON сам передал в Home Assistant

## Что потребуется

- Долгосрочный токен доступа, созданный в вашем профиле Home Assistant в разделе «Безопасность»
- Ничего вводить не нужно, если ViON работает как дополнение Home Assistant: плагин подключается сам
- Для изображений в уведомлениях и открытия события нажатием на уведомление — интеграция ViON для Home Assistant

## Настройки

- **Адрес Home Assistant** — адрес вашего Home Assistant вместе с портом
- **Токен доступа** — долгосрочный токен доступа
- **Исключённые сущности** — идентификаторы сущностей через запятую, которые не нужно предлагать для добавления
