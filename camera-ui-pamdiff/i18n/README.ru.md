# Pam Diff

Обнаруживает движение, попиксельно сравнивая изображение с камеры.

## Возможности

- Попиксельно сравнивает кадры с камеры и сообщает о движении, когда изменилось достаточно пикселей
- Отмечает области, где что-то движется
- Сравнивает либо в оттенках серого, что быстрее, либо в цвете
- Чувствительность настраивается отдельно для каждой камеры
- Есть кнопка, которая возвращает значения по умолчанию

## Настройки

- «Разница движения»: насколько должен измениться цвет пикселя, чтобы это считалось движением
- «Процент движения»: доля изменившихся пикселей, при которой срабатывает обнаружение движения
- «Режим обнаружения»: «Оттенки серого» или «RGB». Оттенки серого работают быстрее
- «Сбросить настройки»: восстанавливает значения обнаружения по умолчанию
