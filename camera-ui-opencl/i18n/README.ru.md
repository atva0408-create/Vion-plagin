# OpenCL

Обнаруживает движение на изображении с камеры и выполняет анализ на видеокарте.

## Возможности

- Обнаруживает движение на изображении с камеры и отмечает области, где что-то движется
- Выполняет анализ на видеокарте
- Позволяет выбрать устройство, которое выполняет анализ, — это полезно в системах с несколькими видеокартами
- Отдельные настройки чувствительности для каждой камеры и кнопка, которая возвращает значения по умолчанию
- Доступен в тесте обнаружения движения и в автоматизациях

## Что потребуется

- Видеокарта с установленным драйвером OpenCL. Без OpenCL на сервере обнаружение движения не запустится
- Если видеокарта не найдена, плагин использует процессор — при условии, что для него установлен драйвер OpenCL

## Настройки

- «Устройство OpenCL»: устройство, которое выполняет анализ. 'auto' — первая найденная видеокарта; остальные варианты — обнаруженные устройства, пронумерованные так же, как в подсказке под полем
- «Площадь»: минимальный размер обнаруженного движения в пикселях. Движение меньшего размера не учитывается
- «Порог»: чувствительность, от 0 до 1. Чем больше значение, тем ниже чувствительность
- «Размытие»: сглаживает изображение, чтобы подавить шум
- «Расширение»: расширяет области обнаруженного движения
