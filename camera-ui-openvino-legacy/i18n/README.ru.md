# OpenVino Legacy

Обнаружение объектов, лиц и номерных знаков для старой графики Intel. С обычным плагином OpenVino такие чипы не могут загрузить модели, и каждая модель молча переходит на процессор.

## Возможности

- Обнаружение объектов: люди, транспорт и животные
- Обнаружение лиц и распознавание лиц
- Находит номерные знаки и читает их текст
- ИИ-поиск по описанию

## Что потребуется

- Используйте его вместо обычного плагина OpenVino, если у вас графика Intel 10-го поколения Core или старше (графика Gen9/Gen11, например HD/UHD Graphics от 610 до 630)
- Он нужен в основном в Windows, где компонент, от которого зависят эти чипы, входит в драйвер графики и не обновляется отдельно
- В Linux с Docker-образом ViON он обычно не нужен: в образе уже есть всё необходимое для старой графики Intel
- На 11-м поколении Core и новее (Iris Xe, Arc) используйте обычный плагин OpenVino: там он быстрее и продолжает получать исправления

## Настройки

- «Устройство»: 'Default' определяет устройство само (NPU, GPU или CPU); AUTO оставляет выбор за OpenVINO; CPU, GPU и NPU задают одно устройство принудительно; варианты с номером, например GPU.0 и GPU.1, выбирают одну из нескольких карт.
- «Активное оборудование»: показывает устройство, на котором сейчас работают модели
- «Модель CLIP (изображения)»: модель ИИ-поиска для всех камер. После её смены переиндексируйте записи.
- «Модель распознавания лиц»: одна модель для всех камер. После смены сохранённые лица обрабатываются заново.
- Для каждой камеры: модели обнаружения объектов, обнаружения лиц и номерных знаков. «По умолчанию» следует рекомендуемой модели.
