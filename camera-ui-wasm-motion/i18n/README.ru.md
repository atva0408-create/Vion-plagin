# WASM Motion

Обнаруживает движение на изображении с камеры. Плагин работает в любой системе и не требует дополнительных компонентов.

## Возможности

- Обнаруживает движение, сравнивая пиксели изображения с камеры, и отмечает области, где что-то движется
- Работает в любой системе без дополнительных компонентов и без видеокарты
- Чувствительность настраивается отдельно для каждой камеры
- Есть кнопка, которая возвращает значения по умолчанию

## Настройки

- «Площадь»: минимальный размер области, который считается движением
- «Порог»: изменение яркости, при котором пиксель считается изменившимся
- «Радиус размытия»: сглаживает изображение перед обнаружением, чтобы снизить шум
- «Размер расширения»: объединяет соседние изменившиеся пиксели в одну область
- «Сбросить настройки»: восстанавливает значения обнаружения по умолчанию
