# Telegram

Отправляет уведомления VION в чаты Telegram через ваш собственный бот: снимок и текст события, сообщения правил зон — всё, что приходит на телефон.

## Что делает

- Каждый пользователь VION подключает свой чат (или группу) по одноразовой ссылке; чат получает уведомления этого пользователя.
- Тихие часы, отключение звука и доступ к камерам действуют так же, как для телефона.
- Уведомление со снимком приходит снимком с подписью; тихие уведомления — без звука.
- Чат, заблокировавший бота, отключается; команда `/stop` в чате отключает его.
- Бот сам забирает сообщения: снаружи до VION ничего доходить не должно.

## Настройка

1. В Telegram откройте @BotFather, отправьте `/newbot` и следуйте подсказкам. Скопируйте выданный токен.
2. Вставьте токен в настройки плагина, поле «Токен бота».
3. Каждый пользователь: VION → «Настройки» → «Уведомления» → «Подключить Telegram», откройте ссылку и нажмите «Start».

## Настройки

- **Токен бота** — от @BotFather.
- **Адрес Bot API** — пусто для api.telegram.org; свой сервер Bot API или прокси, например если Telegram заблокирован.
- **Адрес VION для кнопки** — если задан, у сообщения есть кнопка, открывающая момент в VION.
