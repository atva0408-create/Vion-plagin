# OpenVino

Обнаруживает на видео объекты, лица и номерные знаки и позволяет искать записи по описанию. Оптимизирован для оборудования Intel: процессора, графики Intel или Intel NPU.

## Возможности

- Обнаружение объектов: люди, транспорт и животные
- Обнаружение лиц и распознавание лиц
- Находит номерные знаки и читает их текст
- ИИ-поиск по описанию; с мультиязычной моделью — также на русском и ещё примерно на 100 языках
- Использует детектор, дообученный ViON Cloud на проверенных вами кадрах, как только тот опубликован
- Отвечает «да» или «нет» на вопросы о найденном объекте, которым обучен, например «человек с пакетом»
- Позволяет выбрать конкретное устройство в системах с несколькими видеокартами

## Что потребуется

- Linux или Windows
- В Windows с графикой Intel до 10-го поколения Core включительно (HD/UHD Graphics от 610 до 630) используйте вместо этого плагин OpenVino Legacy: драйверы этих чипов не работают с текущей версией OpenVINO

## Настройки

- «Устройство»: 'Default' определяет устройство само (NPU, GPU или CPU); AUTO оставляет выбор за OpenVINO; CPU, GPU и NPU задают одно устройство принудительно; варианты с номером, например GPU.0 и GPU.1, выбирают одну из нескольких карт.
- «Активное оборудование»: показывает устройство, на котором сейчас работают модели
- «Модель CLIP (изображения)»: модель ИИ-поиска для всех камер. После её смены переиндексируйте записи.
- «Модель распознавания лиц»: одна модель для всех камер. После смены сохранённые лица обрабатываются заново.
- Для каждой камеры: модели обнаружения объектов, обнаружения лиц и номерных знаков. «По умолчанию» следует рекомендуемой модели.
