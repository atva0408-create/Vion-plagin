# Reolink

Подключает к ViON камеры, дверные звонки, видеорегистраторы (NVR) и Home Hub от Reolink по тому же протоколу, которым пользуется приложение Reolink. Работает со всеми моделями Reolink, включая камеры с батареей и модели без RTSP и ONVIF.

## Возможности

- Находит устройства Reolink в локальной сети; остальные можно добавить вручную по IP-адресу или UID
- Прямой эфир почти без задержки, с двусторонним звуком
- Движение, распознанные объекты, плач ребёнка, нажатия дверного звонка и заряд батареи приходят как датчики
- Сирена, прожектор и PTZ с положениями, сохранёнными в приложении Reolink, если они есть у камеры
- Каждый канал NVR или Home Hub и телеобъектив двухобъективной камеры становятся отдельными камерами
- Камеры с батареей спят между событиями, чтобы батарея служила дольше

## Что потребуется

- Имя пользователя и пароль локальной учётной записи камеры, заданные в приложении Reolink
- Камера должна быть доступна с сервера ViON по IP-адресу (порт 9000) или, в том же сегменте сети, по UID
- Камеры с батареей должны иметь доступ к серверу ViON по порту, заданному в настройке «Порт приёма событий»

## Настройки

- **Название камеры**, **IP-адрес**, **UID**, **Добавить камеру**: добавляют камеру вручную; после этого она появляется среди обнаруженных камер
- **Догонять прямой эфир (секунды)**: на сколько изображение может отстать, прежде чем старые кадры будут пропущены; при 0 сохраняется всё
- **Постоянное питание**: для моделей с батареей, постоянно подключённых к питанию, например дверного звонка на звонковом трансформаторе; камера реагирует быстрее, но батарея разрядилась бы за сутки
