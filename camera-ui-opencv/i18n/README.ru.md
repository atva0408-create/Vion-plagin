# OpenCV

Обнаруживает движение на изображении с камеры. Для каждой камеры вы выбираете один из трёх способов обнаружения и настраиваете его чувствительность.

## Возможности

- Обнаруживает движение на изображении с камеры и отмечает области, где что-то движется
- Три способа обнаружения: «Разность кадров» сравнивает каждый кадр с предыдущим, «Вычитание фона» запоминает спокойную сцену и сообщает о том, что от неё отличается, «Стандартный» сравнивает сглаженные кадры с настраиваемым порогом
- Отдельные настройки для каждого способа и каждой камеры
- Кнопка сброса для каждого способа и общая кнопка для всех настроек
- Работает на процессоре, видеокарта не нужна
- Те же способы доступны в тесте обнаружения движения и в автоматизациях

## Настройки

- «Детектор движения»: способ обнаружения для камеры. Изначально выбрано «Вычитание фона»
- «Площадь»: минимальный размер обнаруженного движения в пикселях. Движение меньшего размера не учитывается
- «Порог»: чувствительность. Чем больше значение, тем ниже чувствительность
- «Размытие» (способ «Стандартный»): сглаживает изображение, чтобы подавить шум
- «Расширение» (способ «Стандартный»): расширяет области обнаруженного движения
- «Скорость обучения» (способ «Вычитание фона»): как быстро фон подстраивается под изменения в сцене, от 0 до 1; -1 — автоматически
