# Яндекс Умный дом

Связывает ViON с Умным домом Яндекса и станциями Алисы. Датчики и реле хаба в Яндекс Станции становятся датчиками ViON, сценарии Умного дома запускаются из автоматизаций ViON, станции произносят уведомления вслух, а камеры Умного дома показываются в ViON.

## Что умеет

- **Датчики**: движение, двери и окна, протечки, дым, газ, вибрация, кнопки, температура, влажность, освещённость и CO₂ из Умного дома становятся датчиками ViON. Они могут запускать запись и обнаружение на камерах и автоматизации
- **Управление**: реле, розетки, выключатели и лампы Умного дома становятся выключателями и светом ViON, их включают и выключают автоматизации ViON
- **Сценарии**: каждый сценарий Умного дома предлагается как выключатель. Включили — сценарий запустился, из интерфейса или из автоматизации
- **Голос станций**: при входе как приложение Яндекс каждая станция — получатель уведомлений. Станция, которую вы включили, произносит уведомления: «Движение. Камера во дворе»
- **Ассистент**: ассистент ViON может сказать фразу на станции, дать Алисе команду, запустить сценарий и узнать состояние устройств
- **Камеры**: камеры Умного дома предлагаются в разделе «Камеры» и показывают прямой эфир

## Два способа входа

Плагин работает с любым из них или с обоими сразу.

**Официальный API Умного дома.** API, который Яндекс даёт владельцам Умного дома. Через него плагин читает устройства и сценарии и отправляет команды. Push-уведомлений у API нет, поэтому плагин опрашивает его с интервалом (по умолчанию 10 секунд). Нужно приложение в Яндекс ID с правами iot:view и iot:control:

1. Создайте приложение на сайте Яндекс ID (oauth.yandex.ru): платформа «Веб-сервисы», права «Просмотр списка устройств умного дома» и «Управление устройствами умного дома»
2. Укажите **ID приложения** и **Секрет приложения** в настройках плагина и нажмите **Войти через Яндекс ID**
3. Откройте ya.ru/device на телефоне или компьютере, введите код из окна и нажмите кнопку в окне

Без секрета окно вместо кода покажет страницу Яндекс ID: разрешите доступ, скопируйте токен и вставьте его в окно. Яндекс ID показывает там токен, только если у приложения указан Redirect URI oauth.yandex.ru/verification_code (с https в начале): сначала впишите его в настройках приложения на oauth.yandex.ru.

**Приложение Яндекс (QR-код).** Плагин входит так же, как приложения Яндекса. Этот вход нужен, чтобы станции говорили, и с ним датчики меняются сразу, без опроса:

1. Нажмите **Войти по QR-коду**
2. Отсканируйте код приложением Яндекс (или откройте ссылку на телефоне, где выполнен вход в Яндекс) и подтвердите вход
3. Нажмите кнопку в окне

Если у вас уже есть x_token аккаунта, его можно вставить в поле **x_token** вместо QR-кода.

## Настройки

- **Читать устройства через**: «Автоматически» берёт официальный API, если вход в него выполнен, иначе приложение Яндекс
- **Интервал опроса**: как часто опрашивается официальный API
- **Предлагать сценарии**: сценарии предлагаются как выключатели
- **Голос станций**: «Локально» — напрямую на станцию в домашней сети, текст любой длины. «Облако» — через сценарий аккаунта, работает где бы ни была станция, до 100 символов. «Автоматически» сначала пробует локально
- **Адреса станций**: только если станция не нашлась в сети, в виде `Кухня = 192.168.1.20`
- **Сказать на станции**: проверка голоса фразой на ваш выбор
- **Выйти**: забывает оба входа и то, какие станции говорят. Добавленные датчики и камеры остаются

## Как добавить датчики, камеры и станции

1. Выполните вход, как описано выше
2. Откройте **Датчики** в ViON: устройства Умного дома предлагаются для добавления вместе с комнатами
3. Откройте **Камеры**: камеры Умного дома находятся в разделе **Найденные**
4. В настройках уведомлений ViON, в разделе «Устройства», станции появляются после входа как приложение Яндекс. Ни одна из них не говорит, пока вы её не включите: включите «Активно» у тех, что должны говорить. Это может сделать только администратор ViON

## Полезно знать

- Читаются только устройства ваших домов; дома, к которым вам дали доступ, не читаются
- Если Яндекс больше не принимает вход (сменили пароль, отозвали доступ), плагин один раз пишет об этом в журнал, забывает этот вход и ждёт нового. Второй вход, если он есть, продолжает работать
- Устройство, которое даёт несколько датчиков, называет каждый своим именем и тем, что он показывает, по-английски: «Датчик в прихожей: Motion». Переименуйте их в ViON как удобно
- Голос станций и вход по QR-коду — не официальный интерфейс Яндекса. Изменение на стороне Яндекса может потребовать обновления плагина. Для голоса через облако плагин держит по одному сценарию на станцию с именем «ViON» и идентификатором станции — не удаляйте его
- Микрофон станции сторонним системам недоступен: Алиса слушает только Яндекс. Чтобы говорить с ViON голосом, используйте навык ViON для Алисы в облаке ViON
- Видео камер Умного дома идёт из облака Яндекса
