# ViON NVR

Видеорегистратор ViON: записывает ваши камеры и хранит архив на вашем сервере.

## Возможности

- Записывает каждую камеру непрерывно, по событию (с секундами до и после него) или по запросу: ручная запись длится от 1 до 120 минут, по умолчанию 5.
- Показывает архив на шкале времени с календарём дней, в которые есть запись, паузой, выбором скорости и кадрами предпросмотра.
- Хранит события обнаружения с миниатюрами, фильтрами, избранным и тепловой картой.
- Объединяет события одного визита с нескольких камер в эпизод: например, человек прошёл от ворот к двери.
- Экспортирует отрезок в MP4, в виде таймлапса или сразу несколько камер в ZIP-архиве.
- Может поручить модели ассистента описывать события: их можно искать по тексту в «ИИ-поиске» и получать описание уведомлением.

## Что потребуется

- Тариф ViON Cloud владельца сервера определяет, сколько камер может вести запись и как долго хранится архив. Сервер, не привязанный к ViON Cloud, использует локальные лимиты.
- Для ИИ-описаний: модель ассистента, понимающая картинки (Настройки → Ассистент), и разрешение для ViON NVR.

## Настройки

- «Хранить записи, дней»: более старые видео и события удаляются автоматически; не больше срока, который даёт тариф.
- «Лимит архива, ГБ» и «Минимум свободного места, %»: когда архив превышает лимит или свободного места меньше, удаляются самые старые записи.
- «Записывать звук»: сохраняет звук камер в архиве; по умолчанию выключено.
